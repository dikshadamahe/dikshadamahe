### Things I've built

**[RecovAI](https://github.com/dikshadamahe/RecovAI)** — decision support for copper
flotation at Hindustan Copper. Predicts recovery at R² 0.972 from 26 live process
variables, trained on 1,778 shift logs I digitised by hand.
&nbsp;·&nbsp; [live](https://hcl-recovai.onrender.com/)

**[QuantFactor](https://github.com/dikshadamahe/quant-factor-backtest)** — a
backtesting engine that refuses to lie to you. Point-in-time execution lag, real
transaction costs, and Bonferroni/FDR corrections so a factor that only looks good
because you tried forty of them gets caught.

**[NAFLD Risk Pipeline](https://github.com/dikshadamahe/NAFLD-Model)** — 24
classifiers benchmarked for fatty liver screening on six merged NHANES datasets.
Random Forest led at 0.9644 ROC-AUC; a five-feature logistic regression still
reaches 0.9096, which I find the more interesting result.

**[Veil](https://github.com/dikshadamahe/veil-android)** — a minimalist Flutter
streaming aggregator for Android. Thirty-odd tagged releases and counting.
